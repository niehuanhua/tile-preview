# 排砖预览

卫生间墙地砖排版的小工具 —— 单页网页，本地优先，打开就能用，不用联网、不用安装。

## 这是什么
帮瓦工/业主快速看「砖怎么排」的示意图：哪块是整砖、哪块是裁砖、裁砖实际多宽、包管立柱贴哪边墙角，一目了然。适合发给业主确认效果，也方便现场下料。

## 主要功能
- **门口发整砖**：选好门的位置，地面从门口开始排整砖，零头裁砖甩到对面墙（远端裁砖过小会红字提醒）。
- **包管立柱**：可添加、可改尺寸、可删除；支持「贴左角 / 贴右角」动态吸附，改了墙宽立柱自动跟着贴角。
- **非整砖标注实测尺寸**：裁砖处用红字标出实际毫米数，地面和墙面都生效。
- **图例**：标题下方一行说明，红字=裁砖尺寸、蓝=方位、棕=立柱、白虚线=门窗。
- **墙地通缝**：可指定某面墙压着地面哪条边，自动对齐砖缝。

## 怎么用
1. 找到 `index.html`，**双击**用浏览器打开即可（手机也行）。
2. 在顶部填：墙砖规格、地砖规格、铺法（横/竖）、缝宽。
3. 每张卡片填：墙宽 / 墙高，选门在「上 / 下 / 左 / 右」哪边。
4. 展开「包管立柱」加柱子；展开「门洞 / 窗户」填洞口尺寸。
5. 看图。需要微调就直接改数字，图会立刻重绘。

## 三个工具

| 文件 | 干什么 |
|---|---|
| `index.html` | 卫生间单面墙 / 单块地面的排砖（找坡、蹲便器、门窗洞口） |
| `house.html` | 全屋地板砖通铺：墙把房间隔开，只有门洞相通——门口选「通铺」缝就穿过去、全屋一张网，选「过门石」或没开门洞就各排各的；出下料清单 |
| `房间布局草图.html` | 先把房间拖着摆好（可留墙厚也可贴死）、点墙开门，再一键导给 `house.html` |

`home.html` 是入口目录页，手机上打开它再点进去。

## 数据存在哪
所有填写内容自动保存在**本机浏览器的 localStorage**，关掉再打开还在。换电脑或清浏览器缓存会丢，重要内容记得截图留存。
三个工具各存各的，互不干扰。

## 代码
- 开源地址（公开）：<https://github.com/niehuanhua/tile-preview>
- 纯静态网页，每个工具一个文件搞定（无构建、无依赖、不联网）。
- 验收测试（需要 Node，直接跑即可）：

  ```bash
  node test.js          # 卫生间排砖引擎
  node house-test.js    # 全屋通铺引擎
  node sketch-test.js   # 房间布局草图 + 与 house.html 的跨工具契约
  ```

  前两个文件里的 `/*ENGINE-START*/…/*ENGINE-END*/` 之间的纯函数会被测试用正则抽出来单独运行，
  所以引擎段里不能引用页面上的变量，输入一律走参数。

## 手机上怎么看到新版
改动要生效需要**两条同时满足**：① 推到 `main` 分支（GitHub Pages 才会重建）；
② `home.html` 里对应链接的 `?v=N` 加一（否则手机浏览器继续用缓存的旧页面）。
只改过的那个工具才 +1。
