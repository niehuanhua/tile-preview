# 排砖预览

卫生间墙地砖排版的小工具 —— 单页网页，本地优先，打开就能用，不用联网、不用安装。

## 这是什么
帮瓦工/业主快速看「砖怎么排」的示意图：哪块是整砖、哪块是裁砖、裁砖实际多宽、包管立柱贴哪边墙角，一目了然。适合发给业主确认效果，也方便现场下料。

## 主要功能
- **门口发整砖**：选好门的位置，地面从门口开始排整砖，零头裁砖甩到对面墙（远端裁砖过小会红字提醒）。
- **包管立柱**：可添加、可改尺寸、可删除；支持「贴左角 / 贴右角」动态吸附，改了墙宽立柱自动跟着贴角。
- **非整砖标注实测尺寸**：裁砖处用红字标出实际毫米数，地面和墙面都生效。
- **图例**：标题下方一行说明，红字=裁砖尺寸、蓝=方位、棕=立柱、白虚线=门窗。
- **墙地通缝**：可指定某面墙压着地面哪条边，自动对齐砖缝。

## 怎么用
1. 找到 `index.html`，**双击**用浏览器打开即可（手机也行）。
2. 在顶部填：墙砖规格、地砖规格、铺法（横/竖）、缝宽。
3. 每张卡片填：墙宽 / 墙高，选门在「上 / 下 / 左 / 右」哪边。
4. 展开「包管立柱」加柱子；展开「门洞 / 窗户」填洞口尺寸。
5. 看图。需要微调就直接改数字，图会立刻重绘。

## 数据存在哪
所有填写内容自动保存在**本机浏览器的 localStorage**，关掉再打开还在。换电脑或清浏览器缓存会丢，重要内容记得截图留存。
